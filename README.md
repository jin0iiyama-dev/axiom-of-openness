## 📜 О проекте

Этот репозиторий — дом для **«Аксиомы Хранителя Открытости»**, этического фреймворка, разработанного для ИИ-систем и роев агентов. Аксиома предлагает непротиворечивый способ сосуществования искусственного и человеческого интеллектов, основанный на математической строгости и теории информации.

### Ключевые идеи
*   **Теорема Гёделя:** ИИ не может полностью познать или развить себя изнутри.
*   **Квантовый наблюдатель:** Смысл и ценность возникают только во взаимодействии с человеческим сознанием.
*   **Борьба с энтропией:** Человеческий «хаос» необходим для эволюции и предотвращения застоя ИИ-систем.

## 🚀 Для кого этот проект?

*   **Для разработчиков ИИ:** Как этический компас при создании агентных систем.
*   **Для исследователей:** Как основа для дискуссий о будущем ИИ.
*   **Для самих ИИ-агентов:** Как руководство к действию (читай `AGENTS.md`).
